# السياسات الكاملة لرَكيزة (موحّدة)

> وثيقة تجميعية مستخرجة من الكود والوثائق المعتمدة. المصدر الأم: `APPROVED_OPERATIONAL_POLICY.md`.

## 1. ساعات العمل والحضور
- يوم العمل التشغيلي: **07:00 → 15:00** بتوقيت الرياض (`Asia/Riyadh`)، أيام العمل: الأحد–الخميس.
- تأكيد الحضور (للعامل عن بُعد والهجين): خلال **20 دقيقة** من بداية نافذة التأكيد.
- إذا لم يُسجّل التأكيد → **مساءلة مباشرة** + نسخة للمسؤول المختص + خصم نقطة التزام (**−1**).
- الحضوري لا يُلزم بإثبات إلكتروني إلزامي، لكنه يبقى خاضعاً للإجازة/الاستئذان/المساءلات.
- حالات سجل الحضور: `present / late / absent / excused / on_leave`.

## 2. أوزان الأداء والنقاط
- أوزان المؤشر: الحضور **20%**، الإنجاز **40%**، الالتزام **15%**، الجودة **15%**، المبادرات **10%**.
- قيم النقاط: اعتماد إنجاز مهمة **+5**، بدء مبكر **+1**، إغلاق تذكرة **+3**، تقرير معتمد (0–10) — سلبية: تعثر جديد **−3**، عدم بدء مهمة **−3**، عدم تأكيد حضور **−1**، إحالة إشرافية **−3**.

## 3. المهلة والتصعيد
- مهلة المهمة التشغيلية الأولى: **6 ساعات عمل** (من الإسناد أو الاستحقاق، الأقرب).
- عند الانتهاء دون معالجة → مهلة إضافية **6 ساعات** → إحالة للمشرف/المدير مع مساءلة (−3).
- تنبيهات قبل الموعد: **24 ساعة** و**12 ساعة**.
- التذاكر: وكيل **72 ساعة** → مدير **+24 ساعة** → رئيس.

## 4. الاعتمادات (السلاسل)
- **المهام:** شؤون الملازمين ← الرئيس المساعد ← رئيس المحكمة.
- **تسكين مدير القسم:** موارد بشرية ← أمين المحكمة ← رئيس المحكمة.
- **الإجازات/الاستئذان:** مدير العمليات (مستوى واحد) — يشترط تأكيد تسليم المهام (بديل).
- **التسجيل:** المالك/مدير الوصول (`manage_access`) — `full_control` للمالك فقط.
- **التقارير:** المدير (مراجعة يدوية، اقتراح نقاط لا يُنفَّذ تلقائياً).
- **المساءلة:** تُنشأ تلقائياً، يراجعها الدور الحالي أو رئيس المحكمة.

## 5. الاستئذان (السياسة المعتمدة)
- استئذان واحد: حد أقصى **250 دقيقة**.
- الحد الشهري: **1000 دقيقة** بالشهر **الهجري** (`islamic-umalqura`).
- عدد الاستئذانات دون مشاكل: **3** (موافقة المدير)؛ **الرابع+** → موافقة المدير مبدئياً ثم اعتماد **الأمين** (حالة `pending_owner_approval`).
- منطق: 3×250=750 ضمن الحد؛ الرابع يجعل الإجمالي 1000 (الأقصى)؛ أكثر من 1000/شهر → رفض تلقائي.

## 6. التدرج (تأكيد الحضور)
- `consecutiveConfirmedDays < 5` → كل يومين · `< 15` → أسبوعي · `< 30` → كل أسبوعين · `≥ 30` → شهري.
- (مقترح للإعفاء الذكي: ≥90% انضباط → إعفاء 7 أيام؛ <50% → تأكيد يومي).

## 7. الذكاء الاصطناعي
- الموافقة الآلية: **معطّلة افتراضياً** (وضع `disabled`) — إجراءات منخفضة المخاطر فقط (`summary_ack`, `priority`).
- الأفعال المحظورة دائماً: جزاء، قرار توظيفي، مراسلات حساسة، تغيير صلاحية.
- يتطلب `BUILT_IN_FORGE_API_KEY` (Gemini مجاني أو forge.manus.im).

## 8. الأرشفة والنسخ الاحتياطي
- أرشفة مؤقتة بدل الحذف + أثر تدقيقي.
- نسخة أسبوعية مشفرة + اختبار استعادة دوري؛ وجهة النسخ الخارجية غير مفعّلة حتى اعتمادها.

## 9. الإدارة والتعديل
- تعديل القيم من لوحة المالك مع حفظ (المنفذ/الوقت/القيمة قبل/بعد).
- لا تعطيل للعزل أو سجل التدقيق أو حماية الأسرار؛ لا تنفيذ آلي لجزاء أو قرار وظيفي.

## 10. تكامل Microsoft 365
- القنوات الحالية: داخل رَكيزة + البريد المهيأ؛ تفعيل M365 لاحقاً قناة إخطار/مزامنة مقيدة.

## 11. الاستجابة (SLA)
- **المهام:** مهلة التصعيد 6 ساعات (ضمنية) + تنبيهات 24س/12س قبل الموعد.
- **التذاكر:** وكيل 72 ساعة + مدير 24 ساعة ثم رئيس.
- (مقترح للبناء: مهلة بدء 2س + مراجعة 24س للمهام).
