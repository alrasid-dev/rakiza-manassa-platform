## 【10】السبب الجذري (الأدلة من الكود)

### 🔴 السبب 1: `isTemplateDue` يعيد `true` دائماً للقوالب اليومية
`server/task-automation.ts:181`
```ts
if (frequency === "daily") return true;
```
القوالب اليومية **لا تتحقق من `lastGeneratedAt`** إطلاقاً.

### 🔴 السبب 2: مفتاح منع التكرار يقارن بنطاق "اليوم" بينما الجدولة لـ"الغد"
`server/court-service.ts:5913` + `5924-5927`
```ts
// مفتاح المنع: يبحث ضمن نطاق «اليوم»
const existing = await db.select({ id: tasks.id }).from(tasks)
  .where(and(eq(tasks.templateId, template.id),
             gte(tasks.scheduledFor, start), lt(tasks.scheduledFor, end))).limit(1);
...
const scheduleOffsetMs = now.getTime() > saudiScheduledTime(now, 7).getTime() ? 24 * 60 * 60 * 1000 : 0;
const scheduledFor = saudiScheduledTime(new Date(now.getTime() + scheduleOffsetMs), 7);
```
- `start/end` = نطاق **اليوم**، لكن بعد السابعة صباحاً `scheduledFor` = **الغد 07:00** (خارج النطاق) → لا يجد مهمة قائمة أبداً → **مهمة جديدة في كل تشغيل cron**.

### 🔴 السبب 3: سكربت الاستيراد لا يمنع تكرار القوالب بالعنوان
`scripts/import-women-v2.mjs:114,138`
```js
await db.query("UPDATE task_templates SET isActive = 0 WHERE unitId = 5");
...
"INSERT INTO task_templates (unitId, title, ...) VALUES (5, ?, ...)"
```
- لا يوجد `SELECT` للتحقق من وجود قالب بنفس العنوان قبل الإدراج → كل صف Excel مكرر يُنشئ قالباً جديداً.

## 【12】التوصية

1. **إزالة القوالب المكررة (أولوية قصوى):** دمج القوالب المتطابقة العنوان في قالب واحد (احتفظ بـ defaultAssignee الصحيح)، وأرشفة الباقي مع سجل audit.
2. **إصلاح `isTemplateDue`:** جعل القوالب اليومية تتحقق من `lastGeneratedAt`.
3. **إصلاح مفتاح المنع:** جعل نطاق `existing` يغطي تاريخ `scheduledFor` الفعلي (وليس "اليوم" فقط).
4. **إضافة فحص في سكربت الاستيراد:** قبل إنشاء قالب، تحقق من عنوان مُطابق (بعد توحيد الألف/التاء/الياء) في نفس الوحدة، وحدّث بدل الإدراج.
5. **تنظيف بيانات 2026-10-01:** أرشفة الـ 52 مهمة الزائدة.
